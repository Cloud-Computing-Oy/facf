# Standards for Phase 0 Protocol Simulator

No `agent-os/standards/index.yml` exists in the repository.

The controlling project standards are:

- `docs/protocol.md` — versioned envelopes, identity, offers, leases, and metering;
- `docs/scheduling.md` — mandatory filters, deterministic scoring, and bounded retries;
- `docs/trust-model.md` — explicit trust tiers and revocation;
- `docs/threat-model.md` — fail-closed authorization, replay protection, and minimal telemetry;
- `docs/adr/0001-federate-whole-workloads.md` — one whole workload per execution cell;
- `agent-os/product/tech-stack.md` — OpenAPI-compatible HTTP and a later Go production implementation.
