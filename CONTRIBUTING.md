# Contributing to FACF

Thank you for helping build an open, trustworthy compute fabric.

## Before proposing a change

1. Read the [mission](agent-os/product/mission.md), [architecture](docs/architecture.md), [trust model](docs/trust-model.md), and [governance](docs/governance.md).
2. Search existing issues and discussions.
3. Open an issue first for protocol, security-boundary, economic, or governance changes.
4. Keep each pull request focused and document compatibility and security consequences.

## Quality expectations

- use English for public code, documentation, issues, and pull requests;
- add or update tests with implementation changes;
- never commit credentials, customer data, proprietary model weights, or unlicensed datasets;
- use architecture decision records for durable design choices;
- preserve privacy-safe defaults and explicit user consent for contributed compute;
- run `node scripts/check-docs.mjs` for documentation changes.

## Contribution license

By submitting a contribution, you represent that you have the right to provide it and agree that it is licensed under Apache License 2.0 unless the file clearly states another applicable license.

## Conduct and security

Participation is governed by the [Code of Conduct](CODE_OF_CONDUCT.md). Report vulnerabilities privately according to [SECURITY.md](SECURITY.md).
